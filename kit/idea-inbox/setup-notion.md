# Idea Inbox: Notion

Good if you already live in Notion and want filters and views.

## Create the database

New page > Database (full page). Name it **Idea Inbox**. Add these properties:

| Property | Type | Values |
|---|---|---|
| Title | Title | |
| Verdict | Select | BUILD IT, NOT THIS WAY, NOT NOW, NOT A GOOD IDEA |
| Date | Date | |
| Source | Text | |
| Revisit | Date | When to look again |
| Roles consulted | Multi-select | Your panel roles |
| Related | Relation | Link to the same database |

The page body holds the write-up sections from the idea template.

## Useful views

- **Browse** - gallery view, sorted by date, newest first
- **Due to revisit** - filter: Revisit is on or before today
- **Not now** - filter: Verdict is NOT NOW, sorted by Revisit
- **By verdict** - board view grouped by Verdict

## Getting ideas in

- **By hand:** ask your advisor to "write this up using the idea template," then paste into a new page.
- **Through a connector:** if your AI tool has a Notion connector enabled, ask it to create the page in the Idea Inbox database directly. Review what it wrote; connectors save exactly what they're given.

## Getting ideas back out

To have the advisor check a new idea against your library, export the database (or the filtered view) as Markdown/CSV and upload it, or use the connector to search it.
