# Idea Inbox: Google Drive

Good for Gemini users and anyone whose business already runs on Google Workspace.

## Setup

1. Create a folder: **Idea Inbox**.
2. Inside it, create a Google Sheet: **Idea Index**, with columns:

| Title | Verdict | Date | Revisit | Source | Doc link | Related |
|---|---|---|---|---|---|---|

3. Each idea is its own Google Doc in the folder, using the idea template. Add a row to the index for each one.

## Useful sheet tricks

- **Filter view** on Verdict = NOT NOW, sorted by Revisit, shows what's coming due.
- **Conditional formatting** on Revisit (date is before today) highlights overdue ideas.

## Getting ideas in

- **By hand:** ask the advisor to write it up, paste into a new Doc, add the index row.
- **Gemini:** in a Gem with access to your Drive, ask it to create the Doc in the Idea Inbox folder. Add the index row yourself or ask it to.
- **Other tools with a Google Drive connector:** same idea; check what was saved.

## Getting ideas back out

Give the advisor the Idea Index sheet (and the docs it needs) when you want it to look for connections.
